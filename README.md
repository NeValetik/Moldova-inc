## How to Run  

1. **Install Python**  
   Ensure that Python is installed on your system. If not, download and install it from the [official website](https://www.python.org/downloads/).

2. **Fork the Repository**  
   Fork the original repository and set your forked version as the remote repository. Then, switch to the `pygame-version` branch by running the following commands:  
   ```bash
   git init
   git remote add origin <link-to-your-forked-repository>
   git fetch
   git checkout pygame-version
   ```

3. **Install Requirements**  
   Navigate to the project folder and install the required dependencies using:  
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Game**  
   Execute the `main.py` file to launch the game and experience Moldova Inc.
